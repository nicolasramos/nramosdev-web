## TL;DR

**¿Qué pasa dentro de un LLM cuando genera una palabra? Esta herramienta lo muestra en tiempo real...**

¿Alguna vez te has preguntado qué pasa dentro de la cabeza de un modelo de inteligencia artificial cuando responde a una pregunta? Isham Faizal ha creado el LLM Attention Visualizer: una app web que instrumenta Qwen3-0.6B con 28 tensors post-RoPE para mostrarte en tiempo real cómo cada token contribuye a cada palabra generada. Todo corre 100% en tu navegador via WebAssembly — sin servidores, sin APIs, sin coste. Modelo de 618MB, 600M parámetros, 28 capas de atención, licencia Apache 2.0.
